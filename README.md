
# FastAPI MongoDB CRUD Project

## Project Description
This project is a Notes Manager API built using Python, FastAPI, and MongoDB.

## Technologies Used
- Python
- FastAPI
- MongoDB
- MongoDB Compass
- PyMongo
- Uvicorn

## Features
- Create Notes
- Read Notes
- Update Notes
- Delete Notes

## Installation

Install the required packages:

pip install -r requirements.txt

## Run Project

uvicorn main:app --reload

## API Documentation

http://127.0.0.1:8000/docs
